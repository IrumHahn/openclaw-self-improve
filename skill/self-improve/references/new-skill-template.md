# 새 스킬 초안 양식 (new-skill-template)

`repeat_task` 묶음(같은 열쇠 3번)으로 `new_skill` 제안을 만들 때 `skillMd` 를 이 양식으로 쓴다.

- 이름(`skillName`, 머리말 `name`)은 영문 소문자·숫자·하이픈. 둘이 같아야 한다. 담당 에이전트 작업 폴더의 `skills/` 에 같은 이름이 있으면 거부된다.
- description 에 `(시험판)` 을 꼭 넣는다(없으면 거부).
- 절차는 **메모의 lesson·evidence 와 실제로 했던 단계**에서만 쓴다. 해 본 적 없는 단계를 지어내지 않는다. 모르는 칸은 "대표님에게 확인"이라고 적는다.
- 비밀번호·토큰·계좌·연락처·고객 실명을 넣지 않는다(있으면 거부).
- 20000자 이하. 보통 40줄 안쪽이면 충분하다.
- 메시지에는 `summary` 한 줄만 나간다("주간 매출 정리 — 절차 5단계, 담당 리서처"). 대표님이 "N 보여 줘"라고 하면 전문이 나간다.

```markdown
---
name: <영문-소문자-이름>
description: "(시험판) <한 줄: 무엇을 하는 스킬인지>. Use when <대표님이 이렇게 말할 때>."
---

# <한글 이름>

## 언제 쓰나
- <메모에 나온 상황 그대로>

## 절차
1. <실제로 했던 단계 — 메모 evidence 와 그날 작업에서>
2. ...
(3~7단계)

## 하지 않는 것
- <대표님 승인 없이 보내기·결제·삭제 등>
```
